# DwAvatarPicker

Controlled preset selector for adding a Digital Worker, composed from `DwAvatar`
and native buttons. Clicking the current portrait expands the original 18-avatar
radio grid; Shuffle selects a preset other than the current one. All images are
bundled locally, with no runtime CDN dependency or custom file picker.

## Examples

### Selection inside a field

Every example composes the picker inside `Field` with an avatar label. Selection
uses local React state only: no API provider, fake upload, or network mutation is
needed. The containing form chooses the first preset when it opens.

## API

<Controls of={DwAvatarPickerStories.Default} />

- `preset` is a `DwAvatarPreset` from `DW_AVATAR_PRESETS`, containing a stable
  original image `id` and bundled local `src`. Neither value is a backend URI.
- `onChange(preset)` updates selection only; picking and shuffling never upload.
- `disabled` locks the avatar trigger, all visible radio options, and Shuffle
  throughout the containing form's save transaction.
- `uploading` also locks selection and displays the loading overlay while the
  selected image is prepared or uploaded.
- The shared `useAddDwForm` validates on Save, reads the selected PNG, uploads it
  through the current backend, then creates the DW using the returned URI. Even
  an unchanged default selection is uploaded on Save.
- Upload failure keeps the selection for retry. Closing and reopening the form
  restores the first preset and invalidates pending image work. Add DW and Team
  Invite DW share this flow; Project Cover retains custom-file uploading.

## Token Audit

The picker owns hint text, the shuffle surface and icon, focus and selection rings,
and the uploading overlay. Portrait dimensions, fallback art and clipping are
owned by `DwAvatar` and the UI Avatar.
