# OrganizationAccountMenuSection

The organization group in the account menu reads the current organization and
its saved avatar from the organization query. It composes SICO's Base UI-backed
menu and avatar primitives. Optional management actions belong inside the group,
before its closing divider.

## API

The component accepts optional `children` for organization management actions.
Visibility and navigation stay with the parent. An empty organization list does
not render the group or its divider. Saved `iconUrl` values render as images;
missing or unsafe values retain the organization's initial.

The controls below configure the story's mock API and selected organization,
not additional runtime component props. Story uploads are not live backend
integration tests.

## Token Audit

The section owns text hierarchy and grouping. Menu surfaces, focus states,
avatar shape, and the divider are inherited from the corresponding UI primitives.

### Sizing & shape

| Element              | Class / prop              | Role                                              |
| -------------------- | ------------------------- | ------------------------------------------------- |
| Current organization | `gap-2`                   | Space between the saved avatar and name           |
| Name and description | `text-sm` / `text-xs`     | Primary and secondary text hierarchy              |
| Organization avatar  | `size="xs"`, `rounded-md` | Compact image with initial fallback               |
| Switcher submenu     | `min-w-49`                | Minimum width shared with the account menu recipe |
| Closing divider      | `DropdownMenuSeparator`   | Follows optional management actions               |
