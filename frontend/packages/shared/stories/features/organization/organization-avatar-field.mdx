# OrganizationAvatarField

A presentational avatar picker for the organization edit form. It composes the
shared `Field` and `Avatar` primitives with a native image input; the parent
owns selected-file upload, preview state, and saving state.

## Examples

### Avatar source

The initial state derives one letter from the entered organization name. A
persisted or local preview image replaces that fallback without changing the
field's file-picker contract.

## API

<Controls of={OrganizationAvatarFieldStories.Default} />

- `name` supplies the one-character fallback when neither image source renders.
- `currentIconUrl` is the persisted icon and `previewSrc` takes precedence for
  an in-progress selection.
- `inputRef` connects the visible trigger to the hidden native file input;
  `onPick` receives its change event and is owned by the parent upload flow.
- `uploading` renders the loading overlay, while `disabled` locks both picker
  controls during a save transaction.

## Token Audit

The field owns the avatar fallback surface, primary copy, keyboard focus
outline, and upload scrim. The shared `Avatar` primitive supplies its own
border and image clipping.
